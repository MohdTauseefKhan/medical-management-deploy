## 💡 Overview
The **Medical Management System** is a mini web project developed for academic purposes.  
It allows medical store owners or administrators to:
- Manage users (Owners, Staff, Patients)
- Maintain medicine records
- Handle sales and purchase information
- Track stock and transactions
- Ensure secure authentication and session management

This project demonstrates real-world Java EE concepts including Servlets, JDBC, and MVC architecture.

---

## ✨ Features
✅ User authentication (Login/Logout)  
✅ Role-based access (Owner, Staff)  
✅ Add / Edit / Delete medicine records  
✅ Manage customers and billing details  
✅ Database-triggered updates for inventory  
✅ Session handling and error validation  
✅ Responsive JSP-based frontend
